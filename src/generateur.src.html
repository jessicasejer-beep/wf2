Générateur d'import.csv — ressources numériques

🔒 Aucun envoi de données : vos fichiers ne quittent pas votre ordinateur, tout est traité dans ce navigateur.

1 Choisir le point de départ

Je commence le travail de zéro

Choisissez le dossier qui contient les fichiers à importer. L'outil crée une ligne par fichier, avec le nom exact du fichier : vous n'avez plus à le recopier.

Vous pouvez aussi glisser-déposer le dossier, ou une archive .zip, sur ce cadre. Si le navigateur parle de « téléverser » : rien n'est envoyé, seuls les noms des fichiers sont lus.

Je vérifie un travail déjà commencé

Importez votre fichier de travail Excel (.xlsx) ou un import.csv existant : l'outil le contrôle et vous pouvez le compléter.

Le dossier permet de vérifier que chaque nom du tableau correspond bien à un fichier réel. Glisser-déposer accepté (fichier Excel/CSV, dossier ou .zip).

2 Compléter le tableau

    En-tête bleu : colonne obligatoire En-tête gris : facultatif (enregistré si rempli) Rouge : erreur bloquante Orange : nom de fichier en double (interdit) Jaune : à vérifier uuid : toujours vide
    Utiliser le tableau comme dans Excel
    • Sélectionner : cliquer-glisser ; clic sur un numéro de ligne ou un titre de colonne pour toute la ligne / colonne ; Maj+flèches pour étendre ; Ctrl+A pour tout.
    • Saisir : taper directement, ou double-clic / F2 pour modifier ; Entrée valide et descend, Tab va à droite, Échap annule.
    • Copier / coller avec Excel : Ctrl+C, Ctrl+X, Ctrl+V. Une seule valeur collée sur plusieurs cellules est recopiée dans chacune.
    • Recopier vers le bas : Ctrl+D (la première ligne de la sélection, ou la ligne du dessus).
    • Effacer : Suppr. Annuler / Rétablir : Ctrl+Z / Ctrl+Y.
    • Listes (picto, profil, 0/1, langue, watermark) : cliquer sur la flèche ▾ de la cellule, ou Alt+↓, ou commencer à taper pour filtrer.
    • Les lignes entièrement vides sont ignorées. La colonne uuid reste toujours vide.
    • Les noms de fichiers ne doivent contenir aucun espace (remplacer par « _ » ou « - »).
    • Survoler une cellule colorée (ou la sélectionner) affiche l'explication de l'erreur.

    3 Télécharger import.csv

    À vérifier avant de créer l'archive

    Si un fichier du même nom existe déjà dans votre dossier Téléchargements, le navigateur peut le renommer « import(1).csv » ou « import (1).csv ». Le fichier doit s'appeler exactement import.csv avant d'être placé dans l'archive, à la racine, avec les fichiers des ressources.

    Format produit : séparateur ¤, encodage Latin-1 (ISO-8859-1), 23 colonnes, sans ligne vide.

    Outil autonome — fonctionne hors ligne une fois la page ouverte (lecture Excel et export Excel : bibliothèques SheetJS et JSZip chargées depuis cdnjs).
